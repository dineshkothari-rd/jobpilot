# SkillPath — Learn & Certify

Seven original career-connected paths cover web foundations, JavaScript/TypeScript, React, backend APIs, SQL, Git and computer science. Each has four curated lessons, original practice tasks, a capstone and a short server-graded knowledge check. Suggestions use existing resume skills, target roles and sampled job requirements; they are not proof that a user lacks a skill.

Resources were manually checked on 2026-09-17. Dates, access conditions, alternatives and estimated study times are visible. Publicly accessible material is not automatically open-source. Official resources remain on their publishers' sites; only three verified freeCodeCamp YouTube videos offer opt-in official embeds. CS50 lectures stay external because their licence includes non-commercial restrictions. No videos are downloaded or rehosted. Provider availability and embedding permission can change; use the original internal reading route when blocked.

## Learning Studio

All 28 existing lessons now have original in-app mini-lessons: outcomes, explanations, fictional examples, walkthroughs, mistakes and ungraded reflection feedback. These are introductions and exercise guidance, not full reproductions of the linked provider courses. Publisher references are optional and tucked behind disclosure; earning a provider certificate still requires its separate coursework and account.

The reader supports text size, light/dark reading surfaces, focus mode, tab-local scroll restoration and editable/copyable scratch examples. Scratch examples are explicitly temporary and never executed. Private notes and exercise confirmations continue through the existing owner-scoped versioned save API; all previous lesson IDs and saved records remain compatible. Offline indicators explain that loaded reading remains usable but notes are not durably stored until a successful save.

Release environment check: production already has the existing `SUPABASE_SECRET_KEY`, and a valid-format nonexistent public record returned 404 rather than storage-unavailable, confirming the server can query credential storage. Local `.env.local` lacks this key and therefore intentionally remains preview-only until a developer configures a server-only key and restarts Next.js. Deployment does not fix a separate local environment. Never commit or expose this key; no schema or production environment change is required for Learning Studio.

Supported video loads only after explicit Watch here, with a pre-load privacy notice. The official YouTube IFrame API supplies player readiness/errors, controls, captions, tab-local resume positions and timestamp insertion into the existing private notes. A 15-second setup timeout, script error and provider error all offer the in-app reading route. Resume is user-triggered, not autoplay; watching does not complete exercises. No untrusted HTML, third-party content ingestion, arbitrary code execution, new dependencies, schema changes or environment variables.

## User flow

Choose a path → save private lesson notes, bookmarks and self-reported exercises → build a project → pass the original three-question check → explicitly request a private JobPilot completion record. Print the record using the browser's Save as PDF, or download its HTML. This is not an accredited qualification, identity verification or a provider certificate. Sharing is optional, uses a user-selected public name and exposes no private project or notes. Stop sharing or permanently revoke a record at any time.

Official free provider certificate routes are separate: users must complete the provider's entire current requirements. Manually imported external credentials are clearly unverified. Project evidence can be copied and reviewed in Resume Studio; learning never silently adds experience or qualifications to a resume.
