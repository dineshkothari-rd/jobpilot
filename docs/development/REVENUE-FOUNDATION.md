Register subscription, payment-link, payment and refund events; no client callback grants access. Never enter real card details in test checkout.

A checkout create timeout is ambiguous: its persisted intent prevents an automatic duplicate external POST. Operator recovery must reconcile the actual provider resource against its JobPilot checkout note/reference, account mode, product and amount; never clear a creating intent merely to bypass that guard. A signed checkout event arriving before resource persistence returns a retry response. Owned refresh recovers missed current-period/link payments from canonical provider data. Subscription access uses the **paid invoice's** billing period, rather than a later subscription period. Old refunded payment replays cannot resurrect grants. Renewal cancellation and reconciliation share a lease.

No raw webhook body or payment instrument is stored. Authenticated clients cannot write money state or invoke its mutation RPCs. Test and live credits/entitlements are separate; only live rows influence actual access.
