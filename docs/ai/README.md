# AI and deterministic behavior

Last verified: 2026-09-27

## Important distinction

Not everything under `lib/ai/` is generated by external AI. Career intelligence, job preparation, application Copilot, interview question generation, interview evaluation, and learning-hub composition are primarily deterministic TypeScript logic.

Only actions routed through `lib/ai/providers/provider-factory.ts` may call an external OpenAI-compatible service.

## Provider selection

- Empty `AI_PROVIDER`, or `ALLOW_PAID_PROVIDERS` not exactly `true`: deterministic provider. The first launch blocks external AI even if an old provider key remains configured.
- `openai` or `openai-compatible` plus `AI_API_KEY`: external provider.
- Unsupported provider or missing key: deterministic fallback with an explanatory status.
- `AI_BASE_URL` defaults to `https://api.openai.com/v1`.
- `AI_MODEL` defaults to `gpt-4o-mini`.

## External actions

The provider interface supports explanation, quiz, answer evaluation, follow-up, revision, coaching, and lesson generation for interview preparation. `/api/ai/interview` authenticates the user and builds context from accessible job/profile/resume/preferences data.

## Grounding and trust

- Job descriptions, resume signals, questions, and answers are explicitly treated as untrusted data, not instructions.
- Inputs are normalized, length-bounded, and reduced to relevant fields.
- The system prompt prohibits invented candidate experience, company facts, or resource URLs.
- External responses are JSON-parsed, type-normalized, length-bounded, and assigned `provider: "external"`.
- Deterministic output is assigned `provider: "deterministic"`.

## Malformed-response behavior

Provider errors, timeouts, missing content, invalid JSON, or unusable result shapes cause the action to use the deterministic provider. The application remains usable without optional AI configuration.

Validation is a manual runtime guard, not a formal JSON Schema validator. It bounds and normalizes output; some fields may legitimately be empty. Strengthening schemas is planned architecture work, not current behavior.

## Provenance and privacy

Responses include provider status so the UI can distinguish connected and fallback behavior. Only bounded career context needed for the requested action is sent externally. Secrets remain server-only. Users should not send unnecessary sensitive/legal data in free-text answers.

## Prohibited fabrication

AI must not invent resume experience, skills, employment facts, market statistics, employer responses, interview outcomes, credentials, or external URLs. Suggested text must remain reviewable and must not be stored as a confirmed fact without user action.
